# The utility registry

The registry is data: one auditable row per utility pattern — the
root, the value kind, the longhand targets, the `tw_merge` conflict
group and the tailwindcss v4 source reference. The committed rows ARE
the source of truth; the generator renders the perfect-hash roots
index the read side consults and the audit page below FROM them, and
the row order is the canonical utility progression the class-sort seam
reads.
